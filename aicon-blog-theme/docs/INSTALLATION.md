# Installation

## Before applying the theme

1. Back up the active Blogger theme.
2. Confirm that the blog title, description, HTTPS setting and default language are correct in Blogger settings.
3. Keep the theme file in a UTF-8 editor. Do not paste partial sections into the Blogger editor.

## Apply the XML

1. Open Blogger Dashboard → Theme.
2. Use the Theme menu → Edit HTML.
3. Select the existing source and replace it with the complete contents of `blogger/theme.xml`.
4. Save the theme.
5. Check the home page, one post, a label view, a search view, a static page, an archive and the 404 view.

## Blogger content setup

The theme does not create editorial material. Publish posts normally through Blogger and apply labels that match the navigation or topic sections. The homepage reads `data:posts` from the Blog widget and hides topic sections without matching posts.

Create static pages through Blogger when needed. The theme includes clean article-style rendering for page body HTML and footer paths for About, Contact, Privacy Policy, Disclaimer, Editorial Policy and Terms. The page copy remains the site owner's responsibility.

For the newsletter panel, connect an approved provider or a Blogger gadget in the marked integration area. No provider endpoint is assumed by the theme.
