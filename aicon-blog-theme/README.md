# AiCoN Blogger theme

The complete production theme is `blogger/theme.xml`.

It is a self-contained Blogger XML implementation with:

- Blogger layout version 3 and responsive layout metadata
- dynamic homepage, post, label/search/archive, static page and 404 views
- post title, URL, body, excerpt, image, labels, timestamp, author and comments from Blogger data
- accessible responsive navigation and search
- automatic article table of contents and reading-time calculation
- responsive code, table, image, video and embed styling
- canonical, Open Graph, Twitter and schema.org foundations
- empty states that do not add editorial values

Run `npm run validate` from this directory to parse the theme and check its core data markers. See `docs/INSTALLATION.md` and `docs/DEPLOYMENT.md` for the Blogger and Vercel workflows.
